# Phase 2 — Implementation & Testing

This folder contains the Milestone 2 implementation for the Molema Citrus Estates network project.

## Implementation scope
- Cisco Packet Tracer network implementation
- VLANs and Layer 3 SVIs
- 802.1Q trunking
- DHCP services for Admin, Packhouse, Voice and Guest networks
- Inter-VLAN routing
- Assigned feature: extended ACL traffic isolation for Guest VLAN 50 and Voice VLAN 40
- Connectivity, isolation and troubleshooting verification

## Contents
- `PacketTracer/` — final working Packet Tracer project
- `Configs/` — device configuration records

Testing screenshots are organised in the repository-level `Evidence/` folder and the Milestone 2 report is stored under `Documentation/`.
